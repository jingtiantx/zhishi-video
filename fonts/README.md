Optional: drop font files here (they are git-ignored). `scripts/make_fonts.py` also searches the system font folders.
The default style needs Noto Serif CJK / Noto Serif SC, Bold and Regular. It is licensed under the SIL Open Font License 1.1 and available from https://github.com/notofonts/noto-cjk.
Accepted file names: `NotoSerifCJK-Bold.ttc` / `NotoSerifCJK-Regular.ttc` (face #2 = SC), `NotoSerifSC-Bold.otf` / `NotoSerifSC-Regular.otf` (or `.ttf`), and Source Han Serif SC.
You can also point to the files with `ZV_FONT_BOLD=/path/file[#index]` and `ZV_FONT_REGULAR=…`.
