# Styles registry
| folder | display | orientations | notes |
|---|---|---|---|
| `zhishi-dashang` | 知识大赏（黑金） | landscape, portrait | default black-gold explainer look |
| `_template` | — | — | copy this to start a new style (not selectable) |

A style is a folder with `style.json` and the files it lists. The files must implement the contract in `_template/CHECKLIST.md`.
`python3 scripts/zv.py styles` lists the installed styles.
